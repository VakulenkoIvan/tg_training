# Хвалебный бот «PraiseMe»

Геймифицированный Telegram-бот эмоциональной поддержки от стартапа **PraiseMe Inc.**.  
Бот помогает справляться с бытовой рутиной: превращает повседневные дела в достижения, хвалит голосом выбранного персонажа, выдаёт именные PDF-сертификаты и отслеживает уровень эмоционального выгорания.

---

## Возможности системы

### 1. Подсистема клиента (US-1 — US-7)
* **Мгновенная похвала (US-1):** любое текстовое сообщение воспринимается как выполненное дело и оценивается фразой выбранного персонажа.
* **Выбор персонажа (US-2):** переключение в один клик между **«Бабушкой»** (тёплая забота) и **«Дартом Вейдером»** (эпичная галактическая похвала).
* **PDF-сертификаты (US-3):** генерация именного сертификата формата A4 с уникальным номером в реестре и поддержкой кириллицы.
* **Трекер состояния и реакция на кризис (US-4, US-6):** оценка состояния по шкале от 1 до 10 (по расписанию и вручную). При оценках 9–10 бот выводит бережное сообщение с контактами психологической помощи.
* **График и отчёт (US-5):** построение PNG-графика динамики состояния и недельная статистика по делам и сертификатам.
* **Приватность и право на забвение (US-7):** ФИО не хранятся (используется псевдоним), пользователь может полностью удалить свои данные из БД одной кнопкой.

### 2. Подсистема администратора (US-8 — US-10)
* **Обезличенная статистика (US-8):** количество пользователей, дел, сертификатов и доля прошедших опрос (без доступа к личным оценкам кризиса).
* **Модерация (US-9):** блокировка и разблокировка пользователей по Telegram ID.
* **Журнал событий (US-10):** выгрузка системного лога `bot_events.log` прямо в чат.

### 3. Подсистема мастера / основателя-психолога (US-11 — US-13)
* **Редактор фраз (US-11):** добавление, включение и отключение реплик персонажей без изменения кода.
* **Настройка опросов (US-12):** изменение времени ежедневной рассылки и текста реакции на критические уровни 9–10.
* **Аналитика для инвесторов (US-13):** анонимная сводка по среднему уровню кризиса, доле критических ответов и удержанию пользователей.

## Технологии и архитектура

* **Язык:** Python 3.11+
* **Фреймворк бота:** `aiogram` (FSM, inline- и reply-клавиатуры)
* **База данных:** SQLite (`praise_bot.db`, создаётся автоматически при запуске). Содержит 6 основных таблиц ER-схемы (`Characters`, `Phrases`, `Users`, `Deeds`, `Certificates`, `Crisis_Logs`) и служебную таблицу `Settings`.
* **Графика и документы:** `matplotlib` (генерация векторных PDF-сертификатов и PNG-графиков)
* **Планировщик:** `APScheduler` (ежедневная рассылка опроса состояния)
* **Конфигурация:** `python-dotenv` (хранение токена в `.env`)

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com/VakulenkoIvan/tg_training.git](https://github.com/VakulenkoIvan/tg_training.git)
   cd tg_training
   ```

2. **Установите зависимости:**
   ```bash
   pip install aiogram matplotlib apscheduler python-dotenv
   ```

3. **Настройте переменные окружения:**  
   Создайте файл `.env` в корне проекта и добавьте токен, полученный у `@BotFather`:
   ```env
   BOT_TOKEN=ваш_токен_бота
   ```
   *(Файл `.env`, локальная БД `*.db` и логи `*.log` добавлены в `.gitignore` и не попадают в репозиторий.)*

4. **Запустите бота:**
   ```bash
   python telegram.py
   ```

## Демонстрация ролей

Чтобы протестировать все подсистемы с одного аккаунта Telegram, используйте служебные команды:
* `/start` — запуск бота и главное меню.
* `/help` — справка по функциям.
* `/demo_role` — быстрое переключение роли аккаунта (**Клиент / Администратор / Мастер-психолог**).
* `/admin` — открыть панель администратора.
* `/master` — открыть панель мастера-психолога.
